Assignment Description
Students are required to design and implement an end-to-end Data Warehouse and Business  
Intelligence solution using a selected real-world business scenario. The activity requires  
students to collect and prepare operational data sources, integrate data using ETL processes,  
design a dimensional data warehouse, develop analytical solutions, and present meaningful  
business insights through BI dashboards.
Students must demonstrate practical understanding of concepts covered throughout the  
module, including data warehouse architecture, dimensional modelling, ETL processes, OLAP 
analysis, and business intelligence reporting.
Students should document all implementation steps followed during the activity. The report  
should include relevant diagrams, screenshots, explanations, and analytical findings.
Task 1: Dataset Selection and Business Scenario Identification (10 Marks)
Students must select a suitable real-world dataset representing an operational business  
environment.
The selected dataset should:
 Represent an OLTP system. 
 Contain sufficient records for analytical processing. 
 Include multiple attributes suitable for dimensional analysis. 
 Support the creation of fact and dimension tables. 
 Represent a realistic business scenario. 
Suggested domains:

=== PAGE 2 ===
 Retail / E-commerce, Healthcare, Banking and Finance, Tourism, Education,  
Transportation, Social Media, IoT and Smart Cities 
Students must document:
Dataset Overview
 Business domain 
 Purpose of the system 
 Business problem addressed 
 Dataset source 
 Dataset format 
 Number of records 
 Attributes description 
Students should explain why the selected dataset is suitable for developing a Data Warehouse 
and BI solution.
Task 2: Data Source Identification and Preparation (10 Marks)
Identify and prepare the data sources required for the solution.  Students should use multiple  
source types where possible.
Examples:
 CSV files 
 Excel files 
 Relational databases 
 JSON files 
 APIs 
Documentation should include:
 Description of each data source 
 Source format 
 Available attributes 
 Relationship between sources 
 Data preparation steps 
Students should explain how data from different operational systems can be integrated into a  
unified analytical environment.

Usage of AI: The use of AI tools is allowed for this assessment as a supporting tool for learning 
and development. Students may use AI tools to assist with brainstorming, improving  
explanations, generating ideas, debugging, and refining their work. However, students must  
ensure that the final submission reflects their own understanding and implementation. AI-
generated content should be critically evaluated, verified, and appropriately adapted. Students 
must not use AI to fully generate their assignment, create false results, or replace their own  
technical work. Any use of AI tools should be acknowledged in the report with a brief  
explanation of how AI was used. This assessment follows the CLEAR framework, encouraging 
responsible and transparent use of AI.
